## Every step is a test

I build each part of the model with test-driven development.
First I write one small test that fails. Then I write the minimum code that makes it pass.
Then I clean up the code while all tests stay green.

<TddLoop />

You can do the same. Each section has a starter state with the tests and empty `TODO()` functions.
You can start at any section, because the starter contains the finished code of all earlier sections.

```sh
git clone https://github.com/mohaqeq/kotlin-llm-from-scratch.git
cd kotlin-llm-from-scratch
./gradlew startSection -Psection=ch01-s1   # resets the exercise and shows RED
```
