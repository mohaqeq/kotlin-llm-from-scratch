I am Hamidreza Mohaqeq. I made this project to learn how a GPT-style language model works, from the tensor up.
I chose Kotlin because I use the JVM every day. Also, a language without a deep-learning framework
makes me write every part myself.

## Inspiration and credits

Two works inspired this project. I wrote all text and code here myself. I did not copy from them.

- **Sebastian Raschka, _Build a Large Language Model (From Scratch)_** (Manning, 2024), and its
  [code repository](https://github.com/rasbt/LLMs-from-scratch). The chapters of this tutorial follow a similar path:
  tokenizer, attention, GPT model, training, pretrained weights.
- **[book.humanexperiences.io](https://book.humanexperiences.io/)**, a book that builds an LLM in Node.js and TypeScript.
  It showed me that a language other than Python is a good way to learn this subject.

The sample text in `data/` is _The Verdict_ by Edith Wharton (1908). It is in the public domain.
